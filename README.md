SuperMedicalDoctor is a household doctor assistant that lives in a Telegram group. It keeps each person's appointments, medicines and supplements, reads the lab results someone sends, reminds the appointments and what to prepare for them, and answers health questions from medical sources with the evidence behind them. Every record stays in a private git repo you own. Built for one household; the bot talks Spanish to its users while the code and docs are English.

The first release is being built.
